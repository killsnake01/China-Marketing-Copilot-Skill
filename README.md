# 中国3C营销助手

**中国3C上市决策系统：新品上市策略、负面预警与上线决策工作流。**

面向手机、笔记本、耳机、穿戴设备和智能家居团队。输入产品、上市时间、预算、目标、竞品和已有证据，它会像一场上市评审会一样，输出路线取舍、主张证据、评论区压力测试、负面预警、KOL与渠道动作，以及最终上线判断。

一句话：上市前把四件事说清楚：打哪条线、凭什么信、哪里会翻车、接下来72小时谁做什么；上线后判断继续放大、缩窄主张、切换路线或暂停扩散。

> 本仓库包含 `SKILL.md`，可作为 AI 智能体技能包使用，也可独立阅读作为中国3C上市决策参考。
> 价格、销量、份额、新品参数、KOL近期状态和平台热度都属于高时效信息，正式使用前请按当前日期重新核验。
> 日常创意、文案、KOL、竞品和评论分析默认直接完成当前任务；完整决策包、管理层纪要、评分卡和风险账本按明确需求展开。

## 深度版可交付

| 你会拿到 | 用来解决什么 |
|----------|--------------|
| 上市决策包 | 把包状态、包内目录、面向对象、决策负责人、交接摘要和待决事项放在第一页 |
| 上市总控台 | 直接给裁决、推荐路线、置信度、关键证据状态、第一风险、硬阻断和72小时优先动作 |
| 管理层决策纪要 | 把完整决策压成评审会能读的决策问题、核心取舍、暂停条件和下一负责人动作 |
| 路线裁决 + 路线评分卡 | 推荐、备选、弃用三条路线同尺评分，说明为什么押主线、保留备选或放弃投入 |
| 证据架构 | 核心主张、三条证据柱、已核验事实、待验证事实、推测和禁用表达 |
| 评论区压力测试 | 参数党、普通用户、解构找茬人群会从哪里拆，以及提前准备什么证据 |
| 风险账本 + 负面雷达 | 把“可能翻车”拆成证据锚点、压缩叙事、扩散路径、阈值、负责人和路线影响 |
| 路线切换剧本 | 把继续、缩窄、切换、暂停写成可观察触发器、动作、负责人和截止时间 |
| 上线闸门 | 给出直接执行、调整后执行或暂停重做，附硬阻断项、待补项和72小时动作 |
| 战情复盘 + 决策学习记录 | 上线后把评论、KOL反馈、客服问题和渠道信号沉淀为下次可复用规则 |

完整平台详情页见 [docs/platform-listing.md](docs/platform-listing.md)。

## 适合谁

| 角色 | 典型问题 | 交付价值 |
|------|----------|----------|
| 品牌市场 | 上市方向太多，管理层要一个明确取舍 | 推荐路线、备选路线、弃用路线、决策包和管理层纪要 |
| 社媒与内容 | 文案像通稿，评论区容易被参数拆 | 话术降噪、证据主张纪律、评论区压力测试和替代文案 |
| KOL与渠道 | 排期、口播、评测解禁和评论动作难统一 | KOL简报、平台分工、必说/禁说点、触发阈值和复盘指标 |
| 产品与销售 | 竞品发布后需要快速判断威胁 | 同源数据矩阵、人群影响、可反击点、禁用表达和路线切换 |
| 创业团队 | 团队配置有限，也要完成一次新品上市 | 离线知识库、模板和校验脚本帮助搭出完整评审链路 |

## 为什么值得安装

| 能力 | 下载价值 |
|------|----------|
| 输出结论 | 策略任务要给推荐、备选和弃用路线，减少只堆方案 |
| 一个包交接 | 决策包封面、目录、包状态、负责人和待决事项方便评审会与跨团队交接 |
| 第一屏可汇报 | 上市总控台和管理层纪要先讲裁决、依据、取舍和下一动作 |
| 路线可比较 | 路线评分卡把证据强度、用户匹配、竞品防守、风险可控、资源匹配和时机匹配统一成分数 |
| 风险前置 | 评论区压力测试、风险账本和负面雷达把潜在反噬放到上线前处理 |
| 传播证据分层 | 结构化评论批次区分独立账号、单账号刷屏、跨平台扩散、权威放大和真实业务影响 |
| 旧用法兼容 | 旧提示词、旧术语和熟悉交付形态继续生效，高级模块按需展开 |
| 执行可切换 | 每个关键风险都对应继续、缩窄、切换或暂停动作 |
| 离线优先 | OpenClaw / Hermes 缺少 browser-use、微博、新闻或实时网页能力时，仍可依靠包内知识库和模板完成基础判断 |
| 来源有等级 | 包内来源按已核验、部分可追溯和缺少来源分级，限制过期或缺源材料支撑当前结论 |
| 可验证维护 | 样本、结构规范、黄金样例、来源审计、质量评分、链接检查、脚本安全审计和发布包核验构成回归门禁 |

## 能力边界

- 不编造价格、销量、排名、产品特性、来源或KOL当前状态。
- 无法核验的高时效信息会标注 `[待验证]`。
- 同源不足、知识库无数据和绝对化主张会被标注、降级或拦截。
- 包内来源可追溯程度见 [docs/evidence-ledger.json](docs/evidence-ledger.json)；当前台账仍含部分可追溯和缺少来源资料。
- 不同来源的数据会先说明测试口径，再进行判断。
- 没有实时平台访问时，不声称掌握当前舆情热度或传播趋势。
- 已建立18题跨智能体盲测协议；完成真实全量运行前，不对外宣称各智能体均已通过。
- 已建立12题旧用法兼容合同；静态合同通过不代替真实老用户试用反馈。
- 结构化负面批次只判断用户提供的样本范围，不外推为全网热度或平台整体趋势。
- 上线闸门属于营销决策支持，不替代法务、广告合规和产品安全审核。
