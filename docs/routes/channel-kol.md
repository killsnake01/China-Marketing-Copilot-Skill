# 渠道与KOL路由

## 触发

用户要求 KOL 排期、平台分工、评测解禁、种草计划、评论区动作、直播/短视频节奏或复盘指标。

## 读取顺序

1. `docs/templates/channel-kol-activation.md`
2. `docs/templates/message-house.md`
3. `docs/references/industry-ecosystem.md`
4. `docs/ecosystem/kols.md`
5. `docs/ecosystem/negative-early-warning.md`
6. 用户要求正式上线许可时读取 `docs/templates/execution-readiness-gate.md`

## 必备输出

- 平台角色分工。
- KOL类型、内容任务、必说、禁说和复核点。
- 评论区动作：预埋解释、高赞回应、升级条件。
- 复盘指标。
- 用户要求排期或上市日节奏时增加72小时执行表和7天跟进。
- 用户要求能否上线时增加上线闸门结论和停投/切换阈值。

## 纪律

- 缺少当前 KOL 状态时标注 `[待验证]`。
- KOL人选未知时写筛选条件，不编具体人名。
- 高等级负面触发后，先暂停扩散，再补证据或改口径。
