# 正式物料审核路由

## 触发

用户提供已经成稿的广告、发布会 PPT、官网/电商详情页、KOL Brief、微博文案、口播稿、商品页标题，并要求审核、验收或判断能否发布。

用户要求从零制作老板提案、广告、发布会方案、KOL 合作方案、导演阐述或成片脚本时，主路由根据任务选择 `creative-campaign`、`channel-kol` 或 `messaging-review`，本路由只在后台辅助审核。

## 读取顺序

1. `docs/templates/audience-layering.md`
2. `docs/references/subagent-factchecker.md`
3. `docs/templates/quality-check-tools.md`
4. `docs/templates/risk-assessment.md`
5. `docs/templates/message-house.md`
6. 涉及评论区或上线判断时读 `docs/templates/execution-readiness-gate.md`

## 先判断呈现位置

- 明确要求风险报告、上线审核、执行门槛或内部检查表：审核结构进入正文。
- 要求制作老板提案、创意方案、广告、发布会方案或 KOL 合作方案：先产出受众可见内容，审核结果进入演讲者备注、内部附录或独立检查表。
- 同时要求提案和风险审核：分层交付，不能把完整审核结构混进创意页。

## 必备输出

内部审核层必须保留：

- 问题项、风险等级、依据和替代表达。
- 未验证事实清单。
- 绝对化、对比、价格、权益、KOL 合作和 AI 主张检查。
- 评论区压力测试。
- 上线结论：直接执行、调整后执行或暂停重做。

老板或公众可见层只呈现与当前决定直接相关的结论，并改写为自然会议语言。

## 纪律

- 无法证明的主张直接标注，不替用户抹平。
- 对外物料涉及高风险词时给替代表达。
- 未核验关键事实时，结论不能写 `直接执行`。
- 前台页面不出现智能体指令、审核清单、门槛标签和制作纪律。
- 小型事实脚注可以写“参数待工程确认”，完整测试定义进入备注或内部附录。
