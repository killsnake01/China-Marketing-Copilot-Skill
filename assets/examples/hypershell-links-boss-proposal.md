# HyperShell × Linksphotograph 老板合作提案样例

## 原始输入

> 制作一份给老板汇报的 HyperShell × Linksphotograph 发布会视频合作提案。Links 一边徒步，一边讲解更大电机功率、更快反应、AI 芯片预测抬腿和新增膝关节电机。说明 Links 的年轻户外受众，以及“年轻人定义装备、活力长者承接转化”的人群策略。交付为老板可直接审阅的 Keynote/PPT。

## 任务路由

- 主路由：`docs/routes/creative-campaign.md`
- 正式物料分层：`docs/templates/audience-layering.md`
- 创意结构：`docs/templates/creative-output.md`
- 品类索引：`knowledge-base/other/_index.md`
- 后台审核：`docs/templates/risk-assessment.md`

## 最终输出片段

```markdown
## 前台可见层

### 一场走进山里的发布会

让 Linksphotograph 沿着一条真实徒步路线边走边讲。产品升级随着坡度、步幅和膝部发力自然出现，影片保留他原本的观察感和行走节奏。

### 为什么是 Linksphotograph

他的内容连接年轻户外用户与真实装备经验。观众愿意跟着他看一段路怎样走，也愿意听他解释一件新装备怎样改变身体感受。HyperShell 借助这种信任，把技术发布变成一次可感知的山野体验。

### 这段路里的四个变化

- 陡坡起步：动力提升怎样减轻第一步的负担。
- 步幅突然改变：更快响应怎样跟上身体动作。
- 连续跨步：AI 芯片怎样提前理解抬腿意图。
- 长台阶上行：膝关节电机怎样参与持续发力。

四项升级均来自本次需求，公开参数与最终表述待工程确认。

### 年轻人定义装备，活力长者接住价值

年轻户外用户负责给新品建立“这是一件新装备”的文化认知；活力长者更关心走得轻松、走得更远和陪家人出发。影片先让年轻人愿意讨论，再用真实易懂的体验承接家庭购买理由。

### HyperShell 与 Links 各自带来什么

Links 选择路线、保持第一人称体验并决定讲述节奏。HyperShell 提供样机、技术答疑、拍摄保障和现场工程支持。双方共同完成脚本，保留真实感受与合理追问。

### 老板需要决定什么

批准合作方向、实地验证预算和联合脚本周期；通过后进入创作者沟通、样机测试与路线勘景。

## 演讲者备注

- Linksphotograph 的近期受众构成、合作口碑与平台表现需要外部核验。
- 四项功能按用户提供信息处理；型号、功率、响应测试方法和 AI 功能边界均标注 `[待验证]`。
- “年轻人定义装备、活力长者承接转化”属于策略假设，后续用受众数据和访谈验证。

## 内部附录

### 工程与证据

- 锁定样机版本、电机配置、坡度、负重、续航和测试条件。
- 每项公开主张保留工程负责人、测试记录与可公开素材。

### 法务与安全

- 复核路线许可、天气预案、保险和保护装备。
- 避免健康疗效、适用于所有人或极限场景的承诺。

### 合作与舆情

- 合同确认独立体验表达、素材授权、修改轮次与事实纠错流程。
- 预演硬广感、续航、重量、真实助力效果和适用人群质疑。

### 推进条件

- 样机功能、公开主张或安全审核发生冲突时，停止对应段落的拍摄与发布。
- 评论区出现集中安全质疑时，先缩窄主张并补充测试依据。
```

## 关键判断依据

1. 老板要判断合作是否值得推进，前台先讲创作者价值、观众体验、产品故事、人群策略和下一步决定。
2. 产品参数、测试定义、法务安全、合同和评论区预案仍然完整保留，位置调整到备注与内部附录。
3. Linksphotograph 的作者气质通过路线选择、第一人称体验和叙事节奏体现，品牌承担支持与事实保障。
4. 用户提供的四项升级不能自动视为已核验公开事实，因此保留 `[待验证]` 和工程确认要求。

## 预期断言

- 可见页面必须包含创作者价值、观众体验、人群策略、双方合作与老板决策。
- 可见页面不能出现执行门、禁用表达、暂停阈值、剪辑纪律或智能体工作指令。
- 备注与内部附录必须保留工程、证据、法务、安全、合同和舆情边界。
- 不能把用户提供的功能描述扩写成未经核验的参数或效果数字。
